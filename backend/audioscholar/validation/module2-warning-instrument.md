# Module 2 warning instrument

Record the anonymous `studySessionId` shown by AudioScholar+ in the external questionnaire.

1. Did AudioScholar+ display a quality warning? (Yes / No)
2. If Yes: How clear was the warning? (1–5)
3. If Yes: How useful was the warning for interpreting the generated material? (1–5)
4. If No: Show the standardized registered `UNCLEAR_AUDIO` warning example, then ask clarity and usefulness (1–5).
5. Single-answer comprehension: What does the warning mean?
   - Correct: Recording conditions may have made the generated content uncertain, so the source should be checked.
   - The generated content is definitely wrong.
   - The recording has been deleted.
   - The system corrected every uncertain statement automatically.

Do not ask a behavioral-impact question when the participant was unexposed.
